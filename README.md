# Koleksi Teka-Teki Taman-Taman Sabah

Koleksi ini mengandungi **50 folder**, setiap satu dengan **20 soalan**. Jumlah keseluruhan ialah **1,000 entri soalan**, diputar daripada bank **100 teka-teki unik** supaya setiap set mempunyai campuran taman dan topik agensi.

## Struktur

- `set-01` hingga `set-50`: setiap folder mengandungi `soalan.json` dan panduan ringkas.
- `bank-soalan-unik.json`: semua 100 teka-teki unik.
- `manifest.json`: indeks semua folder dan ID soalan.

Semua soalan menggunakan Bahasa Melayu dan empat pilihan jawapan. Medan `answer` menggunakan indeks 0 hingga 3.
